# GovAI Opportunity Engine

Python-проект на Streamlit: загрузка PDF, DOCX или TXT с компьютера,
а также PDF и публичных HTML-страниц по HTTPS-ссылке;
извлечение текста, просмотр структуры НПА и извлечение административных процессов
через OpenAI с экспортом JSON и проверяемыми ссылками на фрагменты. Интерфейс на русском.
Загрузка и структурирование работают без API-ключа. Для извлечения процессов
нужен доступ к OpenAI API; база данных не требуется.

## Возможности и ограничения

- **PDF:** текст всех страниц по порядку. Нужен текстовый слой; OCR сканов
  пока нет. Для PDF с паролем приложение предлагает загрузить копию без защиты.
- **DOCX:** абзацы и таблицы основного тела документа по порядку, включая
  вложенные таблицы. Колонтитулы, текстовые поля и текст на изображениях не извлекаются.
- **TXT:** UTF-8 (включая BOM) по умолчанию; UTF-16 с BOM и Windows-1251
  можно выбрать в интерфейсе. Автоматического угадывания кодировки нет.
- **URL:** прямой PDF или основной текст HTML через Trafilatura. Явные заголовки
  и номера передаются в тот же `govai.structure.structure_document`, что и файлы.
- Один файл размером до **10 МБ**. Пустые, повреждённые и неподдерживаемые
  документы вызывают понятное сообщение в интерфейсе.
- Результат — обычный текст; исходное оформление и сложная вёрстка не сохраняются.
  В многоколоночных PDF порядок текста может отличаться от визуального.
- Дополнительно сохраняются явные маркеры пунктов и подпунктов, разделы,
  реквизиты с текстовыми доказательствами и физические страницы PDF.
  Неопределённые значения остаются `null`; структура требует проверки.

Документ обрабатывается в памяти процесса Streamlit и не сохраняется приложением
на диск. При локальном запуске обработка происходит на вашем компьютере;
при размещении на сервере файл передаётся этому серверу. Внешние сервисы
для извлечения текста не вызываются. При нажатии **«Извлечь процессы»** фрагменты
документа передаются в OpenAI API; запросы могут тарифицироваться. Статистика
использования Streamlit отключена.

## Установка и запуск

Рекомендуется **Python 3.12**. Все команды выполняйте из корня репозитория.

```bash
git clone https://github.com/shamilovartur/govai-opportunity-engine.git
cd govai-opportunity-engine
# До слияния PR переключитесь на ветку с приложением:
git switch codex/streamlit-document-upload
python -m venv .venv
```

Активируйте окружение:

```bash
# Linux / macOS
source .venv/bin/activate
```

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

Установите зависимости и запустите приложение:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте **http://localhost:8501**, выберите документ и дождитесь появления
поля «Извлечённый текст». Для TXT при необходимости измените кодировку.
Чтобы обработать другой документ, замените файл в поле загрузки.
Остановка сервера: `Ctrl+C` в терминале.

## Загрузка по ссылке

Переключите «Способ загрузки» в **«Загрузить по ссылке»**, вставьте публичный
HTTPS-адрес и нажмите одноимённую кнопку. После получения документа доступны
тот же просмотр текста/структуры и скачивание JSON. Новый запрос удаляет прошлый
результат до загрузки; ошибка не подменяется ранее полученным документом.
Обычный повторный рендер интерфейса и скачивание JSON не вызывают повторный запрос.

Программный вызов:

```python
from govai.url_input import extract_url_document

document = extract_url_document("https://example.org/document.pdf")  # замените адрес
```

В `source` добавляются `type` (`file`, `url_pdf`, `url_html`), исходный
`original_url`, конечный `final_url`, время получения `retrieved_at` в ISO 8601
с UTC и `text_sha256`. У URL-результатов `sha256` относится к полученному телу
ответа после распаковки gzip, а `completeness: "unverified"` не позволяет
считать HTTP 200 доказательством полноты. У локальных файлов URL и время
сетевого получения отсутствуют.

HTML не получает выдуманных страниц: `page_number` и `page_number_basis`
остаются `null`. Trafilatura удаляет оформление и содержимое вне основного
текста. Смещения относятся к **извлечённому тексту**, а не HTML-коду. Автоматические
номера `<ol>`/CSS не достраиваются; явные текстовые номера сохраняются по возможности.

Загрузчик отказывает при 401/403, частичном HTTP-ответе 206/Content-Range,
несовпадении Content-Length, обрыве ответа, незавершённом PDF, странице входа,
заметных признаках подписки/продолжения, оглавлении или слишком коротком тексте
(менее 200 символов после HTML-извлечения). Это консервативные проверки:
короткий полный акт или страница со ссылкой «Открыть полный текст» тоже могут
быть отклонены. Произвольное смысловое усечение автоматически обнаружить
невозможно; для каждого HTML-результата интерфейс просит сверить полноту.
JavaScript, авторизация, обход ограничений и обход связанных страниц не выполняются.

### Сетевые ограничения и защита

- Только HTTPS и порт 443; логин/пароль в URL, localhost, внутренние домены,
  непубличные IPv4/IPv6, нестандартная запись IP и IPv6 transition-адреса запрещены.
- A/AAAA проверяются перед **каждым** переходом. Наличие хотя бы одного
  непубличного адреса или ошибка проверки DNS приводит к отказу.
- Подключение закреплено за проверенным IP; повторного разрешения исходного
  имени при соединении нет. TLS SNI и HTTP Host сохраняют исходное имя,
  сертификат проверяется для него. Это предотвращает замену назначения через DNS rebinding.
- Не более трёх перенаправлений; каждый адрес проверяется заново. Циклы и переход
  с HTTPS на HTTP отклоняются. Автоматические redirects/retries отключены.
- Максимум 10 МБ как полученных, так и распакованных данных; размер проверяется
  и по заголовку, и при чтении. Поддержаны identity/gzip, другое сжатие отклоняется.
- Таймауты подключения/чтения — 5 секунд; DNS — до 5 секунд на запрос A/AAAA.
  Общий бюджет 30 секунд контролируется между сетевыми операциями; это не
  отдельный жёсткий таймер для разбора HTML или каждого байта HTTP-заголовков.
- Cookies и netrc-авторизация не используются. Настроенный администратором
  HTTPS-прокси и CA (`HTTPS_PROXY`, `NO_PROXY`, `REQUESTS_CA_BUNDLE`/`SSL_CERT_FILE`)
  учитываются; даже CONNECT через прокси направлен на проверенный IP.
  Прокси должен поддерживать такой CONNECT и соблюдать его назначение.

Если в окружении запрещён DNS или прокси допускает только доменные CONNECT,
загрузчик покажет ограничение и предложит загрузить файл. Он не отключает проверки
ради обхода политики сети. В управляемом окружении этой итерации внешняя PDF-ссылка
отклонена именно на проверке DNS; успешное скачивание из Интернета здесь
**не подтверждено**. PDF/HTML и 403 дополнительно проверены настоящими локальными
TLS-соединениями, напрямую и через тестовый CONNECT-прокси.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m pip check
python -m pytest -q
```

Тесты создают документы в памяти: проверяют PDF с несколькими страницами,
DOCX с таблицей, кодировки TXT, лимит размера, повреждённые и пустые файлы,
PDF с паролем и без текста. Проверки интерфейса через Streamlit AppTest
покрывают стартовый экран, успешное извлечение во всех форматах и сообщения
об ошибках. Для файлов в AppTest подменяется только загрузчик, извлечение настоящее.
URL-тесты используют контролируемые HTTP-ответы с настоящими PDF/HTML-парсерами.
Проверяются 403, частичные ответы, авторизация, редиректы, DNS, лимиты размера,
gzip, таймауты, IP/TLS-настройки и отсутствие старого результата после ошибки.
В интерфейсных URL-тестах загрузка заменена подготовленным результатом.

Результат этой итерации: **155 тестов прошли** на Python 3.12.14, `pip check`
не выявил конфликтов. В Chromium/Playwright отдельно проверены прежняя загрузка
файлов и URL-режим на контролируемых ответах: PDF, HTML, скачивание JSON,
403, неполный документ, запрет localhost и переключение обратно на файл.
Настоящий локальный TLS-стенд подтвердил загрузку напрямую и через CONNECT-прокси,
правильный Host, закреплённый IP и отказ при неверном TLS-имени. Внешняя
положительная проверка ограничена DNS-политикой текущего окружения, как указано выше.

Для ручной проверки загрузите последовательно TXT, DOCX и PDF с известным
текстом, сравните результат с оригиналом, затем загрузите повреждённый PDF
и удалите выбранный файл. Старый результат должен исчезнуть.

Проверка запущенного сервера из другого терминала:

```bash
curl --fail http://localhost:8501/_stcore/health
```

Ожидаемый ответ: `ok`.

## Формат структурированного результата

`govai.extraction.extract_document(filename, data, encoding=...)` возвращает
обычный словарь, совместимый с JSON. Прежний `extract_text(...) -> str` сохранён.

| Поле | Значение |
| --- | --- |
| `source` | Тип источника, имя, формат, хеши; для URL — исходный/конечный адрес и время получения |
| `text` | Неизменённый результат извлечения; без нормализации пробелов и удаления повторов |
| `pages` | Диапазоны страниц; PDF: физический индекс от 1, DOCX/TXT/HTML: `number: null` |
| `metadata` | Тип, название, номер, дата принятия, дата редакции; каждое значение имеет исходный текст и диапазон-доказательство |
| `sections` | Разделы, заголовки Word и предполагаемые заголовки; `kind` отличает явные признаки от гипотез |
| `clauses` | Только наблюдаемые номера, уникальный ID, родитель (если найден), раздел, список ID фрагментов |
| `fragments` | Текст, точные смещения, строка извлечённого текста, страница, пункт и способ определения принадлежности |
| `warnings` | Машиночитаемые ограничения и неопределённости |

Все `start`/`end` — индексы **символов Python**, от нуля, конец не включён:
`fragment['text'] == result['text'][start:end]`. Это не байтовые смещения,
не координаты PDF и не индексы UTF-16 JavaScript. Конкатенация **всех** фрагментов
восстанавливает `text` полностью, включая пробелы и разделители страниц.

Для будущей ссылки на AI-сценарий сохраняйте `source.sha256`, `source.text_sha256`,
`clause.id` и `fragment.id`. Отображаемого номера недостаточно: номера могут
повторяться в приложениях. Членство в пункте определяет `fragment_ids`, а не весь
интервал `clause.start:end`: внутри интервала могут быть редакционные примечания,
которые сохранены отдельно. Дочерние пункты также имеют собственные фрагменты.

Даты нормализуются в ISO только из явно указанной корректной даты. Дата изменения
другим приказом не считается автоматически датой редакции всего документа.
Номера и реквизиты не берутся из имени файла и не достраиваются по пропускам.

## Извлечение административных процессов

1. Настройте `OPENAI_API_KEY` в менеджере секретов среды размещения или в локальном
   `.streamlit/secrets.toml` (файл исключён из Git). Имя настройки в TOML —
   `OPENAI_API_KEY`. Не добавляйте ключ в код, README, shell-историю или репозиторий.
   Приложение также читает ключ из переменной окружения, если секрет внедряется средой.
2. Задайте модель через переменную окружения **`OPENAI_MODEL`**. Например, в Linux:
   `export OPENAI_MODEL=gpt-4.1-mini`; в PowerShell:
   `$env:OPENAI_MODEL="gpt-4.1-mini"`. Выберите доступную вашему проекту модель
   с поддержкой Responses API и Structured Outputs. Модель по умолчанию не подставляется.
3. Разрешите HTTPS-доступ к `api.openai.com:443` в среде размещения. Системные
   прокси и доверенные сертификаты сохраняются; проверка TLS не отключается.
4. Запустите приложение, загрузите документ файлом или ссылкой и нажмите
   **«Извлечь процессы»**. Раскройте доказательства под каждым действием,
   затем при необходимости нажмите **«Скачать процессы JSON»**.

Текст в поле просмотра не редактирует исходный документ для анализа. Кнопка отправляет
его структурированные фрагменты в API; обычный рендер и скачивание результат повторно
не запрашивают. При смене документа или неудачной новой попытке старый результат удаляется.
Без ключа, модели, при отказе, лимите API, таймауте, обрезанном или неверном JSON выводится
ошибка. Демонстрационных результатов и автоматической подмены провайдера нет.
Ошибка любого блока не позволяет выдать частичный результат за завершённый анализ.

### Как устроен анализ

- `govai.llm.OpenAIProvider` вызывает Responses API со строгой JSON Schema,
  `store=False`, отключённым автоматическим усечением и лимитом вывода 12 000 токенов.
  Таймаут запроса 90 секунд, не более одного повтора SDK при временных ошибках.
  `store=False` не означает отсутствие всех служебных журналов у провайдера:
  обращайтесь к правилам хранения данных вашего API-проекта.
- `govai.processes` зависит только от протокола `ProcessProvider.extract(payload)`.
  Другой адаптер должен возвращать `Candidates`; проверка источников и объединение
  не зависят от OpenAI. Production-интерфейс использует только настоящий OpenAI-адаптер.
- Разбиение следует наблюдаемым разделам, пунктам и заголовкам. В основном блоке
  до 6 000 символов и 100 фрагментов; помещающийся пункт сохраняется целиком.
  Длинные пункты/фрагменты делятся по словам с исходными ID и смещениями.
  Каждый символ входит ровно в один основной блок. Добавляются до 1 200 символов
  с каждой стороны и до 6 000 символов заголовков/начал родительских пунктов;
  ограничение контекста отмечается в `coverage.chunks[].context_limited`.
  По умолчанию максимум 200 блоков; превышение вызывает ошибку до вызова API.
  Это ограничения символов, не обещание совместимости с контекстом любой модели.
- Из каждого блока извлекаются кандидаты процедур и действий, исполнитель,
  входы, результаты, условия и зависимости с доказательствами. Неизвестные
  сведения остаются `null` или `[]`. Определения и перечни не должны превращаться
  в действия; это правило инструкции модели, а не доказанная семантическая гарантия.
- Для цитат проверяются существование ID и точное совпадение **в переданном тексте**.
  Возвращаются все подходящие диапазоны символов, исходный пункт, способ привязки
  и физическая страница PDF. HTML/DOCX/TXT не получают выдуманных страниц.
  Ложное основное доказательство отклоняет действие; неподтверждённое дополнительное
  поле удаляется с причиной в отчёте. Номера пунктов модель не генерирует.
- Процедуры объединяются по подтверждённому исходному пункту/заголовку/фрагменту.
  Точные нормализованные повторы действий с общим местом доказательства сливаются;
  разные описания или условия сохраняются. Перефразированные дубли и ошибочная
  группировка процедур возможны и требуют ручной проверки.

**Совпадение цитаты доказывает расположение, но не смысл вывода.** Все действия
имеют `requires_review: true`, `validation: "exact_quote_match_only"`.
Покрытие всех символов не гарантирует полноты извлечения процессов моделью.
Дальние зависимости между разделами могут не попасть в ограниченный контекст;
автоматическая проверка юридической корректности не выполняется.

В JSON сохраняются источник и его хеши, модель/провайдер, время анализа, версия
инструкции, процедуры, действия, цитаты, причины отклонений и покрытие блоков.
Пустой список содержит объяснение модели по блокам; отклонение всех кандидатов
явно отличается от утверждения модели об отсутствии действий.

Для настоящего запуска из командной строки ключ должен быть внедрён в окружение:

```bash
python -m scripts.extract_processes examples/rosimushchestvo_261/source.txt \
  --output work/261.processes.json --check-261
python -m scripts.extract_processes tests/fixtures/law_59_article8_excerpt.txt \
  --output work/59.processes.json
```

`--check-261` только добавляет отчёт о найденных якорях 3.2–3.8 **после** анализа;
он не влияет на запросы или алгоритм. При необходимости уменьшите `--core-chars`.
CLI читает секрет из окружения, UI дополнительно поддерживает Streamlit Secrets.
Второй файл — явно обозначенный отрывок другого НПА, не полный закон.

Отчёт о текущих проверках и ограничениях реального запуска:
[docs/process-extraction-quality.md](docs/process-extraction-quality.md).
Автоматические тесты LLM используют mock-ответы и не подтверждают качество настоящей модели.
AI-инициативы, экономика и приоритизация не реализованы.

## Известные ограничения

- Правила выделения структуры эвристические. Явный маркер не доказывает, что это
  юридический пункт: это может быть элемент списка или поле формы. Ненумерованные
  и перенесённые заголовки распознаются частично; `heading_candidate` требует проверки.
- Продолжение пункта относится к последнему явному маркеру до обнаруженной границы.
  После неоднозначного списка принадлежность не назначается. Сложные сноски,
  вложенные списки, таблицы и нестандартная вёрстка могут потребовать ручной разметки.
- PDF: номер — позиция страницы в файле, а не напечатанный номер. Пустые страницы
  не исчезают. Повторяющиеся строки на краях сохраняются как `layout_candidate`;
  иногда это может быть содержательный текст. OCR и восстановление колонок отсутствуют.
- DOCX не имеет надёжной физической пагинации без отдельного рендеринга.
  Автоматическая нумерация Word не вычисляется: её отсутствующие в тексте номера
  не выдумываются. Колонтитулы, текстовые поля, отслеживаемые правки и изображения
  не входят в поддерживаемый текстовый слой.
- Сохранность фрагментов проверяется относительно извлечённого текста. Она
  не доказывает, что PDF/DOCX-библиотека извлекла все видимые элементы оригинала.
  Для юридически значимых выводов нужны сверка с оригиналом и проверка редакции.

## Структура

```text
app.py                     # Интерфейс Streamlit
govai/extraction.py         # Извлечение и проверка документов
govai/structure.py          # Структура, реквизиты и точные ссылки на текст
govai/url_input.py          # Безопасная загрузка HTTPS и извлечение HTML
govai/processes.py          # Блоки, контракт LLM, цитаты, объединение кандидатов
govai/llm.py                # OpenAI Responses + Structured Outputs
govai/process_ui.py         # Иерархия процедур, доказательства и экспорт
.streamlit/config.toml     # Лимит загрузки и отключение телеметрии
requirements.txt           # Зависимости приложения
requirements-dev.txt       # Зависимости для тестов
tests/                     # Тесты извлечения и интерфейса
examples/rosimushchestvo_261/ # Реальный НПА, источники и пример результата
scripts/build_npa_example.py # Воспроизведение примера без сети
scripts/extract_processes.py # Настоящий вызов API и отчёт по якорям приказа 261
```

Файлы `.env`, `.streamlit/secrets.toml`, виртуальное окружение и временные
файлы исключены через `.gitignore`. Секреты требуются только для LLM-извлечения процессов.
